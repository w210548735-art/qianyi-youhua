## 已知风险

- SQLite + NumPy 全量扫描适合第一阶段演示和小规模数据；资产量显著增长后应迁移到专用向量索引。
- DeepSeek 属于外部服务，仍会受网络、额度、响应格式变化影响；当前已提供明确错误码与事务回滚。
- Conda `DL` 环境存在 Requests 依赖版本警告和历史无效发行版警告，本次测试未受影响，建议后续单独清理环境。
- 演示页按要求只保证功能，不提供鉴权、权限角色和视觉设计；生产部署前必须补齐认证授权。
